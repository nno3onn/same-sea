# 같은 바다

말없이 같은 바다를 바라보는 3D 해변 프로토타입입니다. 서울의 시간과 일출·일몰, 현재 날씨에 따라 장면이 바뀝니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 빌드나 계정은 필요하지 않습니다. Three.js, SunCalc, [Open-Meteo](https://open-meteo.com/)를 불러오므로 인터넷 연결이 필요합니다.

## 조작

- `WASD` 또는 방향키: 걷기
- 마우스 오른쪽 드래그: 시점 회전
- 휠: 확대·축소
- 모래 클릭: 해당 위치로 걷기
- 화면 버튼: 파도 소리, 하트 그리기, 앉기

오디오는 브라우저 정책에 따라 버튼을 누른 뒤 재생됩니다. 이 페이지는 정적 웹 프로토타입이며 사용자 행동을 서버에 저장하지 않습니다.

## 현재 상태

수면 반사, 파도 거품, 젖은 모래, 낮과 밤, 날씨 표현을 실험 중입니다. 화면과 음향은 아직 실사 수준이 아니며, 일부 시점에서는 수평선에 어두운 선이 보일 수 있습니다.
