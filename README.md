# 같은 바다

말없이 같은 바다를 바라보는 3D 해변 프로토타입입니다. 서울의 시간과 일출·일몰, 현재 날씨에 따라 장면이 바뀝니다.

## 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 빌드나 계정은 필요하지 않습니다. Three.js, SunCalc, [Open-Meteo](https://open-meteo.com/), Supabase Realtime을 불러오므로 인터넷 연결이 필요합니다.

## 조작

- `WASD` 또는 방향키: 걷기
- 마우스 오른쪽 드래그: 시점 회전
- 휠: 확대·축소
- 모래 클릭: 해당 위치로 걷기
- 화면 버튼: 파도 소리, 하트 그리기, 앉기

오디오는 브라우저 정책에 따라 버튼을 누른 뒤 재생됩니다. 같은 바다에 접속한 사람의 위치와 동작은 Supabase Realtime으로 전달합니다. 연결이 끊기면 다른 캐릭터를 표시하지 않습니다. 한 브라우저 프로필에서 여러 탭을 열어도 한 탭만 참여합니다. 서로 다른 브라우저나 시크릿 창을 같은 컴퓨터에서 사용하는 경우는 별개의 방문자로 처리됩니다. 위치와 동작은 데이터베이스에 저장하지 않습니다.

## 현재 상태

수면 반사, 파도 거품, 젖은 모래, 낮과 밤, 날씨 표현을 실험 중입니다. 화면과 음향은 아직 실사 수준이 아니며, 일부 시점에서는 수평선에 어두운 선이 보일 수 있습니다.
